# Module 01 · Congressional affairs alternative

This is a self-contained, fictional alternative to the course's logistics case. You are an agency congressional affairs analyst reviewing an AI draft response to a House subcommittee staff inquiry. The task is to decide whether the draft's **SEND** recommendation is supported by the records available at the decision time.

Start with [LAB.md](LAB.md). The nine-file case packet is under [case/](case/); the work-folder starter copies it into a separate attempt. The later source update is released by the starter only after you freeze your baseline work.

The exercise keeps Module 01's core moves: identify source authority, check exact identity/version/time, split mixed claims, redo arithmetic, trace eight handoffs, challenge mismatched sources and embedded instructions, freeze a verdict, isolate a later change, and test a fresh-session handoff. It uses Codex and local files; no OMP or model API key is needed.

The organizations, inquiry, portal rules, records, and deadlines in this packet are invented for training. No real congressional submission is involved. The original course module and its automated logistics checker do not apply to this alternative case.
