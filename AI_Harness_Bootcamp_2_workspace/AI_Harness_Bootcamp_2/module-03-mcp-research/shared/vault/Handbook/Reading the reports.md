# Reading the reports

Plain-words guide to the terms in the research pile.

| Term | Meaning |
|---|---|
| DTG | Date-time group. `081400Z OCT 2026` is the 8th, 14:00 Zulu, October 2026. |
| Zulu (Z) | Universal time. |
| Local (L) | Base local time, UTC plus three hours. `081630L` is 13:30 Zulu. |
| LOGSTAT | A logistics status report: what a unit has on hand and how fast it uses it. |
| Class VIII | Medical supplies. Burn-dressing cases are Class VIII. |
| Lot | One manufacturing batch. A lot carries its own quality status and expiry date. |
| QA hold | A quality office stops a lot from being issued until it has checked it. |
| Deadlined | A vehicle that cannot be used until it is repaired. |
| MSR, ASR | Main supply route and alternate supply route. |
| MLC | Military load class: the weight class of a vehicle or of a bridge limit. A vehicle above a bridge's posted class must not cross. |
| Serial | One movement unit in a convoy table. |
| Sortie | One helicopter flight. |
| PMLC | The partner medical liaison cell. |
| BMLO | The Base Medical Logistics Officer. |
| FB | Forward base. |

Two reports that look alike can describe different things. A stock count is not the amount that can be issued, and an approved flight is not a flight that can fly.
