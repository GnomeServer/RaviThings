## Perspectives

### Skeptic
Absence is not loss. The week is already past the frozen standard's ten-module envelope. Most old labs were tool tours. Assumption challenged: every unowned old objective is a hole. Unique view: reject any insert that cannot name the Monday-morning decision it changes.

### Outsider
Reformation is the common rating. Persistent state, adaptive loops, multi-agent work, MCP construction, and weight changes are later ratings. Staff text already requires recognizing when to call the later rating. The labs never ask. Assumption challenged: "advanced" in a staff file means taught. Unique view: the missing artifact is a classification record.

### Historian
Six decision rules survived the tools. An instruction the model can ignore is not a control. Fan-out is a cost you justify against one agent. A permission does not make material true. Write the refusal before the endpoint exists. Report degradation as a count. Weights are the last surface. Reformation forces pieces of the permission and refusal rules. It replaced endpoint comparison with an instruction comparison plus a local standup that proves presence. The first, second, and sixth rules have no learner evidence. Assumption challenged: the old labs are the unit of transfer.

### Futurist
Connectors, custom instructions, and "add an agent" requests will still arrive. A fine-tuning lab gets less useful for this audience. The decision not to tune gets more useful. Assumption challenged: P9's execution path is the valuable half of Friday.

### Advocate
The person going back to Copilot, ChatGPT, or Claude will not build a hook or an MCP server. They will paste a custom instruction and enable a connector someone sent them. Cost without a choice is theater. Fit of the local model they just stood up is the choice they have. Assumption challenged: Model Economics as a briefing is what they lacked.

### Conflicts and agreements
Agreement: do not restore the builder labs, do not add a fifth day, do not reopen today's person-to-person cut. Conflict: the skeptic would stop there. The others want four evidence records because the staff boundary claims a skill the labs do not produce.

## Synthesis and Recommendation

Bring four records into modules that already exist. Leave the builder arc out.

1. Connector refusal, Module 03, before the supplied server is connected. One specimen whose description overclaims read-only or tells the model to hide which tool answered. The learner writes the refusal from those words, then connects only the course server. OSD's first objective. Not OSD's build.

2. Advice versus enforcement, close of Module 06. One supplied pair: a saved instruction that says always and was not loaded, beside the predicate just configured, which fires without the model. The learner names which pile each rule is in. Harness Control Plane and P2 taught this by building hooks. The build stays out.

3. Machine choice, close of Module 07, replacing a weaker close-out. Three supplied workloads: the graph just saved; one case whose next step depends on a check; one case that asks for several readers. Classify fixed, adaptive, or hybrid. Name the simpler method, the added risk, and the escalation owner. Do not run the other two. Note common mode on the multi-reader case. This is the recognition task the staff files claim and course.json does not contain.

4. Fit of the local model, inside Module 10, no new paid lane. A supplied five-case pack of hosted versus local replies, scored for a named job, plus the one live local reply already produced set beside the matching supplied hosted reply. That one row is observed. The learner states what got worse and which surface the behavior belongs on: saved instruction, checker, tool boundary, or not weights. No training job. No claim that five cases measure the model.

Leave out on purpose: B1 dashboard and live Codex correction; Model Economics as its own briefing; P2 authoring; MCP handshake memorization; P3 and PG operation; OSD construction; P4's MCP write path and integrity mutation; P5 as a separate lab; the loops briefing and Pi lab; P6's Goose loop; P7's AI-filled columns; P8's listener and 30-60-90; P9's training job; the install fault tree, pocket card, and human-gate economics handout.
